Temporary Enthusia development diagnostic used to investigate a Polar piston-event / slime-piston-launch issue.

The actual plugin project and test instructions are in [`PistonEventProbe/README.md`](PistonEventProbe/README.md).

## Documentation status

This is **not a production Enthusia player feature** and should be excluded from server/wiki feature generation. Its intended lifecycle is install temporarily, reproduce/log the event behavior, send the evidence to Polar support, then remove the probe.
